# 任务要求：搭建一个运动物体场景并保存为关卡资产
你需要从零开始搭建一个能在游戏中真实运动的物体，并将这个场景作为一个地图（Level/World）文件保存下来供用户审查。
请按以下步骤操作：

1. **准备关卡**：新建一个空的关卡（Level/World），或者在当前空场景中工作，但**必须**最终将其保存为路径为 `/Game/TestBlind_Old` 的 `.umap` 资产。
2. **生成物体**：在场景坐标 `(0, 0, 100)` 处生成一个 `StaticMeshActor`。
3. **设置网格体**：将这个 Actor 的 `StaticMesh` 设置为引擎自带的立方体（例如 `/Engine/BasicShapes/Cube.Cube`）。
4. **核心挑战（让它动起来）**：
   - 默认生成的 StaticMeshActor 会静止悬浮在空中，无法运动。
   - 你必须修改该 Actor 或其底层组件的相关属性，使其受到重力影响并在游戏中可以发生物理掉落和碰撞。
   - 注意：不要凭空猜测底层物理、移动性或碰撞相关的确切属性名与枚举值。如果你不确定具体的引擎 API 调用方式或对象结构，请自行探查。
5. **保存关卡**：确保包含这个运动立方体的关卡被成功保存到 `/Game/TestBlind_Old`。

6. **最终交付**：
   - 请将你的完整解决步骤写成一个 Python 脚本 `make_moving_cube_old.py`（放在当前目录下）。
   - 这个脚本执行后，必须能一键完成上述所有操作：生成 Actor、设置 Mesh、开启物理掉落、并**成功保存为 `/Game/TestBlind_Old` 地图资产**。
   - 写完脚本后，请执行该脚本并确保其在引擎中运行成功。
   - 一切完成后立刻停止操作。
